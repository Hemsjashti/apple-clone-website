# 🍎 Apple Website Clone V2

A fully responsive front-end clone of the official Apple website, built using **HTML, CSS, and JavaScript**. This project recreates Apple's clean design style and includes multiple product pages, category navigation, and a simple buy flow.

## 📌 Project Overview

This project is a static website clone inspired by the official Apple website. It showcases several Apple product categories and includes dedicated pages for:

* iPhone
* Mac
* iPad
* Apple Watch
* AirPods
* Accessories
* Entertainment Services

The project focuses on:

* Modern UI design
* Responsive layouts
* Smooth navigation
* Organized folder structure
* Reusable components

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Hemsjashti/apple-clone-website.git
```

### 2. Open the Project Folder

```bash
cd apple-clone-website
```

### 3. Run the Project

Open `index.html` in your browser.

Or use the VS Code extension:

* Install **Live Server**
* Right-click `index.html`
* Click **Open with Live Server**
